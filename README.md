# 🤖 AI Engineer Roadmap & Anotações de Estudo

Repositório dedicado a centralizar o mapeamento de competências, conceitos-chave, arquiteturas de sistemas de IA e recursos de estudo para a transição de carreira para Engenharia de IA.

---

## 🧭 Guia de Execução (Mentalidade de Mercado)
> ⚠️ **Importante:** Estudar apenas a teoria não forma um AI Engineer. O mercado valoriza a prática.

### 📌 Ordem Recomendada de Aprendizado:
1. **LLM + APIs** (Conexões básicas e parâmetros)
2. **RAG** (Injeção de contexto e bases de conhecimento)
3. **Embeddings** (Busca semântica e vetores)
4. **Agentes** (Loops de autonomia e tomada de decisão)
5. **Produção & DevOps** (Monitoramento, custos e segurança — *estudar em paralelo*)

## 🚀 Portfólio: Projetos de Alto Impacto para Desenvolver
Construir esses projetos valida seu conhecimento prático para o mercado:
* [ ] **Chat com Base de Conhecimento (RAG):** Chat que responde com base em PDFs ou dados internos de uma empresa.
* [ ] **Automação de WhatsApp com IA:** Agente integrado a mensagerias para atendimento/triagem.
* [ ] **Agente Operador:** Um robô autônomo que executa tarefas fim-a-fim (ex: busca dados, filtra e gera relatório).
* [ ] **Sistema de Tool Usage:** LLM conectada a APIs externas realizando chamadas baseadas na intenção do usuário.
* [ ] **Dashboard de Observabilidade:** Painel com métricas de uso de IA, tracking de custos e latência.
